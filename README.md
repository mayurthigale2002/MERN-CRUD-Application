# MERN Employee Management System

A full-stack Employee Management System built using the MERN Stack (MongoDB, Express.js, React.js, Node.js) with JWT Authentication and Employee CRUD operations.

---

# Features

- User Registration & Login
- JWT Authentication
- Protected Routes
- Employee CRUD Operations
- React Frontend
- Express Backend APIs
- MongoDB Database
- Bootstrap UI
- Axios API Integration

---

# Tech Stack

## Frontend
- React.js
- React Router DOM
- Axios
- Bootstrap

## Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcryptjs
